## [1.0.10] - Previous Release

### Features
- Natural language travel search support (fliggy-fast-search)
- Structured hotel search support (search-hotels)
- Flight query support (search-flight)
- Attraction search support (search-poi)
- Multiple intent recognition pattern matching
- Markdown formatted output support
- Automatic image and booking link display

### Technical
- Based on Fliggy MCP services
- Node.js runtime
- Single-line JSON output for pipeline processing

## Version Notes

### Semantic Versioning Rules

- **Major**: Incompatible API changes
- **Minor**: Backward-compatible new features
- **Patch**: Backward-compatible bug fixes

### Change Log Types

- **Added**: New features
- **Changed**: Changes to existing functionality
- **Deprecated**: Features to be removed soon
- **Removed**: Removed features
- **Fixed**: Bug fixes
- **Improved**: Performance or UX improvements
- **Security**: Security fixes
